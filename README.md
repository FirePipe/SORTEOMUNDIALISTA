# 🏆 Sorteos: Sistema de Asignación de Números
### *Fisher-Yates Unique Distribution • Audited Security*

Este proyecto es una plataforma interactiva, segura y visualmente atractiva diseñada para la gestión, visualización y proyección en vivo de sorteos y rifas de premios mayores.

## ✨ Características Principales

*   **🛡️ Distribución Segura (Fisher-Yates):** Implementación del algoritmo Fisher-Yates auditado para garantizar una distribución de números 100% aleatoria y transparente.
*   **📺 Modo de Proyección Profesional:** Pantalla completa optimizada para transmitir o proyectar el sorteo en tiempo real a los participantes.
*   **📋 Ficha Técnica Dinámica:** Visualización interactiva del premio principal (ej. Televisor QLED, dimensiones, puertos, imágenes) con un diseño moderno y oscuro.
*   **🎱 Tablero de Balones:** Interfaz para el seguimiento visual e intuitivo de las balotas y números asignados.
*   **🔐 Panel de Administración:** Acceso seguro para administradores para la configuración y ejecución del sorteo.
*   **🤖 Integración con Inteligencia Artificial:** Potenciado por Gemini (Google AI Studio) para optimizar la interacción, reglas y condiciones de los sorteos.

## 🛠️ Tecnologías Utilizadas

*   **Frontend/Backend:** Node.js, React / Next.js
*   **Estilos:** Tailwind CSS (o la librería que utilices para ese genial modo oscuro)
